Drop the submission screenshots here; they will render in the main README.

| File | What it shows |
|---|---|

| `recall-leitner.png` | Leitner-X Review card with Again/Hard/Good/Easy grading |
| `examiner-radar.png` | Examiner evaluation — marks, missing points, model answer |
| `gpa-lab.png` | GPA Lab — CGPA ring, required-GPA feasibility, scenarios |
| `rtl-arabic.png` | Any module with `<html lang="ar" dir="rtl">` mirroring |
| `study-buddy.png` | Study Buddy widget with avatar picker + rename |

Tip: screenshots of **real data** (an actual uploaded material, real mastery
numbers) are far more persuasive to judges than staged placeholder content.
